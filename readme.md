# MartaValério_Parte A

Como o quadro original não é um quadrado perfeito, defini o canvas com 800 × 784 px, mantendo a proporção e respeitando a largura mínima pedida de 800 px. Coloquei a imagem de referência no Illustrator onde medi a posição e a espessura de cada linha e de cada retângulo. Com essas medidas esbocei uma folha com as medidas em pixéis e acabei por usar rect() para tudo, incluindo as linhas pretas.
Cores: Linhas pretas (4, 6, 3); Vermelho (238, 36, 0); Amarelo (253, 220, 0); Azul (35, 33, 118); fundo “branco” (233, 237, 232)
Textura: Acrescentei ainda uma textura para reproduzir mais fielmente o quadro. Fiz loadImage(), image()- onde defini o seu tamanho de maneira a ocupar todo o Canvas.
